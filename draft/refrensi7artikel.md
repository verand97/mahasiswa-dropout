     1. Villar & de Andrade (2024) - Springer Nature

     * Judul    : Supervised machine learning algorithms for predicting student
     dropout and academic success: a comparative study
     * Jurnal   : Discover Artificial Intelligence (Springer Nature), Vol. 4, Art.
     79
     * Tahun    : 2024
     * Dataset  : Dataset Mahasiswa UCI (ID: 697) - 4.424 data
     * Metode   : Random Forest, SVM, Naive Bayes, Decision Tree + SMOTE Standar
     * Metrik   : Akurasi, Precision, Recall, F1-Score
     * Temuan   : SMOTE standar mampu meningkatkan Recall kelas minoritas dropout,
     namun rentan membuat sampel tiruan di area noise karena tidak memperhitungkan
     jarak batas keputusan (decision boundary).
     * Tautan DOI Langsung (Bisa Dibuka):
       https://doi.org/10.1007/s44163-023-00079-z

     2. Ridwan & Priyatno (2024) - Journal of Education and Computer Applications

     * Judul    : Predict Students' Dropout and Academic Success with XGBoost
     * Jurnal   : Journal of Education and Computer Applications (JECA), Vol. 1, No.
     2, Hal. 78–86
     * Tahun    : 2024
     * Dataset  : Dataset Mahasiswa UCI (ID: 697)
     * Metode   : XGBoost Classifier tunggal
     * Metrik   : Akurasi, Precision, Recall, F1-Score
     * Temuan   : XGBoost sangat efektif memisahkan mahasiswa dropout vs lulus
     berdasarkan SKS semester awal, namun belum mengukur kurva PR-AUC untuk kelas
     minoritas dan belum membandingkannya dengan CatBoost pada fitur kategori.
     * Tautan DOI Langsung (Bisa Dibuka):
       https://doi.org/10.69693/jeca.v1i2.13

     3. Nti & Ramanayake (2026) - Springer Nature

     * Judul    : Explainable machine learning for student dropout prediction and
     tailored interventions in online personalized education
     * Jurnal   : Discover Artificial Intelligence (Springer Nature), Vol. 6, Art.
     1016
     * Tahun    : 2026
     * Metode   : Ensemble Gradient Boosting + Explainable AI (SHAP & LIME)
     * Metrik   : F1-Score, ROC-AUC, Mean Absolute SHAP Value
     * Temuan   : Menerapkan SHAP untuk membongkar alasan model memprediksi
     mahasiswa putus studi, membuktikan bahwa transparansi model sangat penting agar
     kampus dapat memberikan intervensi personal yang tepat sasaran.
     * Tautan DOI Langsung (Bisa Dibuka):
       https://doi.org/10.1007/s44163-026-01016-6

     4. Bettahi, Belouadha, & Harroud (2025) - MDPI (Scopus Q2)

     * Judul    : A Modular and Explainable Machine Learning Pipeline for Student
     Dropout Prediction in Higher Education
     * Jurnal   : Algorithms (MDPI), Vol. 18, No. 10, Art. 662
     * Tahun    : 2025
     * Metode   : Modular ML Pipeline (Tree Ensembles) + SHAP
     * Metrik   : Precision, Recall, F1-Score, SHAP Global Attribution
     * Temuan   : Membangun pipeline modular untuk deteksi dropout perguruan tinggi
     dan menunjukkan bahwa integrasi XAI menjamin keterulangan (reproducibility)
     serta akuntabilitas keputusan akademik.
     * Tautan DOI Langsung (Bisa Dibuka):
       https://doi.org/10.3390/a18100662

     5. Albugami, Wali, & Almagrabi (2026) - PeerJ (Scopus Q1)

     * Judul    : Predicting student dropout in Saudi Universities using machine
     learning and explainable AI
     * Jurnal   : PeerJ Computer Science, Vol. 12, e3490
     * Tahun    : 2026
     * Data     : 5.000+ data historis akademik universitas
     * Metode   : Random Forest, Gradient Boosting, XGBoost + SHAP TreeExplainer
     * Metrik   : Accuracy, Recall, Macro F1, ROC-AUC
     * Temuan   : Analisis SHAP TreeExplainer membuktikan riwayat akademik semester
     awal dan status beasiswa/ekonomi merupakan faktor paling krusial pembeda
     mahasiswa lulus vs dropout.
     * Tautan DOI Langsung (Bisa Dibuka):
       https://doi.org/10.7717/peerj-cs.3490

     6. Devkishan, Singh, & Bharti (2024) - IEEE Xplore

     * Judul    : Implementation of Machine Learning and Ensemble Learning
     Techniques to Proactively Predict Students' Academic Success in the Realm of
     Higher Education
     * Prosiding: IEEE ICTACS 2024 (IEEE Xplore)
     * Tahun    : 2024
     * Dataset  : Data Akademik Pendidikan Tinggi (4.424 baris, 36 atribut)
     * Metode   : Voting Ensemble, Bagging, Gradient Boosting
     * Metrik   : Akurasi, Precision, Recall
     * Temuan   : Model gabungan (ensemble learning) secara signifikan mengungguli
     model tunggal konvensional dalam mengenali mahasiswa yang berisiko tidak lulus.
     * Tautan DOI Langsung (Bisa Dibuka):
       https://doi.org/10.1109/ictacs62700.2024.10840530

     7. Endahti (2026) - Jurnal Terakreditasi Nasional

     * Judul    : Analisis Pengaruh SMOTE Terhadap Bias Keputusan Model Machine
     Learning pada Prediksi Dropout Mahasiswa
     * Jurnal   : Rabit : Jurnal Teknologi dan Sistem Informasi Univrab, Vol. 11,
     No. 2, Hal. 210–221
     * Tahun    : 2026
     * Metode   : Algoritma Klasifikasi Machine Learning + Analisis Bias SMOTE
     * Temuan   : SMOTE konvensional rentan meningkatkan kesalahan prediksi jika
     sampel sintetis dibuat di area batas kelas yang kabur, sehingga
     merekomendasikan perlunya teknik penyeimbangan data berbasis batas keputusan
     (borderline-aware).
     * Tautan DOI Langsung (Bisa Dibuka):
       https://doi.org/10.36341/rabit.v11i2.8275
